# درجات — نظام إدارة الدرجات والجلاءات للمدارس

موقع متعدد المدارس (Multi-tenant) مبني على منطق ملف الإكسل الأصلي: رصد الدرجات، حساب الفصلين (الدرجة النهائية = ROUNDUP((ف1+ف2)/2))، السلوك، الجلاء، البيانات، الترتيب، التفقيط (نسخة JavaScript من دالة NoToTxt في VBA).

## التشغيل
```
npm install
npm run seed          # (اختياري) مدرسة تجريبية: admin/admin123 ، teacher1/teacher123
SUPER_PASS=كلمة_سر_قوية PORT=3000 npm start
```
يتطلب Node 22.13 أو أحدث. البيانات في مجلد `data/` (SQLite) — خذ نسخة احتياطية منه دورياً (أو حدّد DATA_DIR).
حساب المزوّد (أنت): المستخدم `owner` وكلمة السر من SUPER_PASS (وإلا تُولَّد وتُطبع عند أول تشغيل).

## البيع لعدة مدارس
1. ادخل بحساب المزوّد ← «مدرسة جديدة» ← حدد الاسم واسم دخول المدير وتاريخ انتهاء الاشتراك والقوالب (السابع…البكالوريا).
2. كل مدرسة معزولة تماماً عن غيرها (طلابها ودرجاتها ومستخدموها).
3. عند انتهاء الاشتراك تتحول المدرسة إلى «عرض فقط».
4. ضعه خلف HTTPS (Nginx/Caddy) على أي استضافة تدعم Node.

## الأدوار
مزوّد (owner) · مدير مدرسة (admin: كل شيء) · معلم (رصد مواده المسندة فقط).

## التشغيل بـ Docker
```
cp .env.example .env      # عدّل SUPER_PASS
docker compose up -d --build
```
الموقع على المنفذ 3000، والبيانات في مجلد `data/` (انسخه احتياطياً).
